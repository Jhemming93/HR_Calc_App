Grab expected value explained

Expected value is a way to combine every possible Grab outcome into one long-run average. It is useful for comparing a spin's cost with the probability-weighted value of what can come out of it.

What expected value measures

Each possible item contributes to the average based on two things: its chance of appearing and its realistic resale value. A valuable item with a tiny probability may contribute less to the average than a modest item that appears frequently.

A simple example

Imagine a simplified Grab with two outcomes. One has an 80% chance and is worth 100g. The other has a 20% chance and is worth 1,000g. Before selling fees, their weighted contributions are 80g and 200g, for an average gross value of 280g per spin.

If the spin costs more than the expected net value after selling fees, the long-run expected profit is negative. If it costs less, the expected profit is positive.

Why one spin tells you almost nothing about the average

Expected value describes an average across many comparable trials. You can hit a rare item immediately or miss it for a long time. A positive expected value therefore does not mean the next spin is likely to produce a profit, and a negative expected value does not mean every spin loses.

Use the exact probabilities shown for that Grab

Do not assume a universal rarity rate. The calculator should be fed the displayed probabilities for the specific Grab you are evaluating. If multiple items share a rarity, only divide a rarity's probability equally when the game's information supports that assumption.

Resale value is the weak link

Probability may be displayed clearly, but resale value is an estimate. If you enter inflated listing prices, the expected value will also be inflated. For a more useful result, use realistic sale values and test a conservative scenario.

Include every outcome

Leaving out low-value outcomes makes a Grab look better than it is. Outcomes you would keep, cannot sell, or consider worthless still need to be represented. If you assign them 0g resale value, their probability correctly lowers the overall average.

Fees should be applied consistently

If you plan to sell outcomes on the Marketplace, the fee should be reflected in the expected net proceeds. Mixing gross values for some items with net values for others produces an inconsistent result.

Special mechanics can complicate the model

Guarantees, pity systems, changing odds, or multi-pull bonuses can make a sequence of spins different from repeated independent trials. A simple one-spin expected value remains a useful baseline, but it may not capture the value of the entire sequence.

What the Grab calculator is best for

  • Comparing the cost of a spin with a complete set of displayed probabilities.
  • Testing how much a rare item's resale price affects the average.
  • Seeing whether a Grab still looks attractive under more conservative prices.
  • Understanding how selling fees change the long-run result.
Key distinction: expected value answers “What is the average result under these assumptions?” It does not answer “What will I get on my next spin?”
